# Public operation wire coverage

The denominator is the **85 unique public HTTP operations** recorded by Task 1 in [implemented-api-audit.json](implemented-api-audit.json), baseline revision `f12ce06810f602fce08c048476c9a522c862c83e`. That audit is retained as an explicit pre-repair baseline; its Swift signatures are not the current API inventory. This matrix maps those same 85 `METHOD /3/path` keys to current public calls and named request/response tests: **85 covered, 0 uncovered**.

Reconciliation by family: account 11, authentication 3, lists 7, movies 23, people 11, search 1, trending 4, TV 25. The current source has 101 public operation method declarations: 82 method families map to the 85 keys because trending has four resource paths; 17 compatibility overloads, the additional search overload, and the legacy account accessor account for the other 19 declarations. Utility methods (`updateAuthenticator`, `clearCaches`, `cacheDiskStorageSize`) are not HTTP operations. Internal endpoint-only declarations, including guest-session creation, do not enlarge the denominator.

Every primary test below invokes the public API and compares returned typed fields to literal fixture/example values. Fixture-driven tests also assert independent literal method/path/query/body/header expectations at the URLProtocol boundary. Endpoint declarations select fixture files only; they never supply expected requests. Optional-query tests deliberately ignore decoding and supplement a primary response test; they are not counted as response coverage. Complete query equality checks omissions, and duplicate keys are checked before dictionary conversion. Query order is irrelevant.

`K` means exactly `api_key=123` and no Authorization header. `U` additionally means exactly `session_id=456`. `G` means exactly `guest_session_id=guest`, with no user session key, even when both credentials are available. GET bodies and streams are absent and Content-Type is absent. Mutation bodies are complete JSON objects; JSON comparisons retain number/Boolean distinctions. Content-Type, when present, is exactly `application/json;charset=utf-8`.

The harness creates isolated URLCache instances for each injected client/session, resets its global handler in setup/teardown, and holds a shared recursive lock across each test lifetime. Runs are serial (`swift test` without `--parallel`). Fixture stubs count expected requests, so cache hits or missing invocations cannot satisfy their primary tests. The temporary negative probe changed a movie expectation to `/3/WRONG-PATH`; the actual `/3/movie/143` request failed at the test call site. The wrong expectation was restored before commits.
